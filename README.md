## 👨‍💻 About Me

I'm a **Full-Stack Software Engineer** focused on building reliable, scalable, and maintainable software from the backend to the frontend and through to production deployment.

My experience spans **web application development, backend engineering, REST APIs, databases, Linux systems, DevOps, CI/CD, and deployment automation**. I enjoy working across the entire development lifecycle — from understanding a problem and designing a solution to writing code, testing, deploying, monitoring, and improving it.

My core development experience includes **PHP/Laravel, CodeIgniter, JavaScript, Python, React, Django, Flutter, SQL databases, and Linux-based environments**, with a strong interest in backend architecture, cloud infrastructure, automation, and system reliability.

## 💻 Development Philosophy

I believe good software should be:

* **Maintainable** — easy for other developers to understand and extend
* **Reliable** — designed to work consistently in real-world conditions
* **Secure** — security considered throughout the development lifecycle
* **Scalable** — capable of growing with users and business requirements
* **Automated** — repetitive processes should be automated where possible
* **Well documented** — important decisions and implementations should be understandable

I focus on solving the **problem behind the software**, not simply writing code.
